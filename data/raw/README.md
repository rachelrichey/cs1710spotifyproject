# Raw data

Put the team's dataset here as **`spotify_tracks_with_dates_gender.csv`** (114,000 rows, 27 columns, ~50 MB).

It is not tracked by git (see `.gitignore`) because of its size. Share it through the team drive, or use Git LFS if you prefer to keep it in the repo.
The processed JSON that the website needs is already committed in `public/data/`, so you only need this file to rebuild the data.
